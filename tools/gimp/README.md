# GIMP Script-Fu preprocessing helper

You can use this script to preprocess your images in GIMP 3.0 to get a bit better image quality.

> Make sure to cut out the image to a 1:1 ratio, otherwise it will get rescaled to 1:1.

| Before | After |
|---|---|
| ![without preprocessing](./without-preprocessing.jpg) | ![with preprocessing](./preprocessed.jpg) |

## Install

1. Clone the repository
2. Copy the `instax-square-prep.scm` to `~/.config/GIMP/3.0/plug-ins/instax-square-prep/instax-square-prep.scm`
3. Restart GIMP
